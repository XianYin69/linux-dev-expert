# 知识树（九叶 · 不可再拓扑）

## 拓扑判据

- 新增叶须同时满足：不与上述九叶的「主问句」重叠、有独立探测脚本、有独立权威出处。
- 语言语义（C++ 模板、Python 生态）不入本树 → 转派 c-expert / cpp-expert / python-expert。
- 界面与前端不入本树 → 转派 interface-design-expert；Windows 平台不入本树。
