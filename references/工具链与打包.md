# 工具链与打包

| 出处 | 原始链接 | 用途 |
|---|---|---|
| GCC 手册与源码 | https://gcc.gnu.org/onlinedocs/ | 选项语义、LTO、sanitizer、目标三元组 |
| Clang/LLVM | https://github.com/llvm/llvm-project | 诊断、libc++、交叉编译工具链 |
| GNU make | https://www.gnu.org/software/make/manual/ | 规则、模式匹配、并行与依赖图 |
| CMake 文档与仓库 | https://cmake.org/cmake/help/latest/ | toolchain 文件、find_package、生成器表达式 |
| Meson | https://mesonbuild.com/ | 跨编译 native file、pkg-config wrap |
| pkg-config / pkgconf | https://systemd.io/PACKAGE_CONFIG_SPECIFICATION/ | .pc 搜索路径与依赖展开 |
| Debian Policy Manual | https://www.debian.org/doc/debian-policy/ | deb 打包、依赖与多架构规则 |
| Fedora Packaging Guidelines | https://docs.fedoraproject.org/en-US/packaging-guidelines/ | rpm spec 与依赖生成 |
| Alpine / musl | https://musl.libc.org/ | musl 与 glibc 行为差异、静态链接 |
| ELF 规范（TLS/i386/abi） | https://refspecs.linuxbase.org/elf/elf.pdf | 段、符号、重定位、版本节点 |
| binutils | https://sourceware.org/binutils/docs/ | ld、readelf、objdump、符号版本脚本 |

## 使用规则

- 编译/链接选项须给「作用 + 副作用 + 版本要求」，如 `-static-pie`、`-Wl,--as-needed`。
- 打包结论须区分发行版族；跨族命令并列给出或明确限定适用范围。
- 交叉编译须核对 sysroot、三元组、`pkg-config --define-variable` 与 rpath 处理。
