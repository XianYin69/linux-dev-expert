# 标准与手册

结论优先引这些出处；引用时须带版本号与实测命令。

| 出处 | 原始链接 | 用途 |
|---|---|---|
| The Single UNIX Specification (POSIX.1-2024) | https://pubs.opengroup.org/onlinepubs/9799919799/ | 接口契约、errno 语义、线程与信号标准 |
| Linux man-pages | https://www.kernel.org/doc/man-pages/ | 系统调用、库函数、flags 的 Linux 实际语义 |
| glibc 手册与源码 | https://www.gnu.org/software/libc/manual/ | 扩展接口、locale、DNS、malloc 调参 |
| Linux kernel 文档 | https://docs.kernel.org/ | epoll/io_uring/cgroups/namespaces 特性页 |
| kernel.org 源码 | https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git | 行为存疑时读实现，不读二手博客 |
| man7 在线手册 | https://man7.org/linux/man-pages/ | 快速查 syscall 与 flags |
| syscall(2) 与 errno(3) | https://man7.org/linux/man-pages/man2/syscall.2.html | 直调与错误码约定 |
| getconf / sysconf 变量表 | https://man7.org/linux/man-pages/man3/sysconf.3.html | 运行时上限（_SC_OPEN_MAX、_NGROUPS_MAX） |

## 使用规则

- 版本敏感条目（glibc ≥ 2.34 默认合并 pthread、io_uring 内核版本要求）必须写明版本。
- 手册与实测冲突时以实测为准，并在结论里标注差异与复现命令。
- 不得凭记忆写 syscall 号、结构体字段或 flag 值；一律 `man 2 <name>` 或头文件核对。
