# 过程链存取

## 规则

1. 流程状态用过程链存取：`python scripts/process_chain.py` 的 `start / step / interrupt /
   resume / finish / show` 六个动作，不得凭记忆推进流程。
2. 进入任一步骤先 `step <步骤名>`；步骤完成由脚本落时间戳，人工不得改写历史条目。
3. 审查或校验失败必须 `interrupt --reason <归因> --at <步骤>`，修复后 `resume` 回到原节点，
   禁止「失败后直接跳到下一步」。
4. 存储位置：用户缓存目录（`~/.cache/linux-dev-expert/process_chain.jsonl`），
   不写技能目录。
5. 两条路径互不交织：创建路径 `finish` 即结束，不得再进修改流程；修改路径完成标记为
   「完成项目修改」。
6. 收口必查：`process_chain.py show` 显示创建路径 10 步全部 done，缺步即不得称完成。
7. 与调度方交接：完成时输出末条记录（含时间戳）供上层整合；本技能不代替上层续排。

## 降级

- 链文件损坏：以 `git log` 的功能分支提交序列重建步骤状态，重建过程记逻辑链。

## 违反后果

- 跳步导致约束未写、脚本未校验即交付；中断未记录则失败原因丢失，重试无依据。
