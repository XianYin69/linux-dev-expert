# 垃圾回收机制

## 规则

1. 一切生成物先落 `tmp/`（技能根下，已被 `.gitignore` 忽略），不得直接写技能正式目录。
2. `tmp/` 内容经审核后由 `python scripts/garbage_collect.py release --yes` 释放到目标位置；
   释放后删除 `tmp/` 内对应文件，不留残余。
3. 缓存文件（探测输出、下载物、索引缓存）一律落**用户缓存目录**
   （`$XDG_CACHE_HOME/linux-dev-expert/` 或 `~/.cache/linux-dev-expert/`），
   禁止写入技能目录。
4. 探测脚本的 `--json` 输出默认打印到 stdout；写文件时路径必须在 `tmp/` 或用户缓存目录。
5. 收尾必查：`python scripts/garbage_collect.py audit` 报告 `tmp/` 与技能目录内的
   缓存/临时产物清单，非空即不得称「完成」。
6. 未指定目标目录时按 [`沙盒机制`](../沙盒机制/沙盒机制.md) 在固定路径沙盒作业，交付后删沙盒。

## 降级

- 释放失败（目标已存在且内容不同）：保留 `tmp/`，输出 diff 供用户裁决，不得覆盖。
- 审计发现技能目录内有缓存：移动到用户缓存目录并记逻辑链，不直接删除（可能是取证物）。

## 违反后果

- 技能目录被临时产物污染，版本历史失真，交付体积虚高，且缓存随技能同步外泄。
