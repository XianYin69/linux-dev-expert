# resistance（约束库 / 兜底库）

## 遵守原则

1. 修改本目录内容须经自更新接口（`python scripts/self_update.py --help`）审批流程。
2. 违反本目录的操作不得执行，除非有显式兜底方案覆盖并留逻辑链。
3. 本目录变更须记入 [`../CHANGELOG.md`](../CHANGELOG.md) 并注明违反后果。
4. 不得删除本目录任何约束文件（红线）。
