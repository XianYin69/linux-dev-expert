# 薄技能依赖约束

## 规则

1. **只引用不内嵌**：本技能正文（SKILL.md、agent/、asset/、references/）不得复制
   c-expert、cpp-expert、python-expert、concurrency-design、database-management、
   interface-design-expert、code-guidelines 等技能的内容；只写名称、边界与调用方式。
2. **声明即契约**：所有依赖必须同时出现在 [`dependence/dependence.md`](../../dependence/dependence.md)
   与 `dependence/deps.json`，每条附 `source_url`（本地技能 `local://<id>`，
   软件给上游原始链接）。缺 `source_url` 即判不合格。
3. **转派触发点**：命中下列情形即转派，不得就地硬答——
   C/C++ 语言语义与 UB → c-expert/cpp-expert；并发架构（锁层级、无锁结构）→ concurrency-design；
   Python 生态实现 → python-expert；存储与迁移 → database-management；
   界面与交互设计 → interface-design-expert；提交前规范审查 → code-guidelines。
4. **缺失降级**：依赖不可用时给「缺失影响 + 按发行版族的安装命令 + 可继续的替代路径」，
   不得静默跳过，也不得伪造已调用。
5. **写盘边界**：本技能只写自己的目录。挂接（在他技能里加指向本技能的声明）由调用方统一做，
   本技能不得改动他技能文件。
6. **校验**：`python scripts/deps_check.py` 必须通过（字段齐全、source_url 非空、
   本地技能目录存在）。

## 违反后果

- 内容重复导致两处漂移、口径冲突；越权改动他技能破坏其版本历史与审查结论。
