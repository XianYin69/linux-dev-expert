# 收尾

生成提示词、释放 tmp、走 git 合并、清理并交回调度方。

## 节点

1. **提示词四格式**：`agent/CLAUDE.md`、`agent/agent_prompt.md`、`agent/instructions.md`、
   `agent/.cursorrules`，一句话口径「使用 `linux-dev-expert` skill 来完成用户请求」。
2. **自更新释放**：`python scripts/self_update.py compare` → 确认无误 →
   `release --yes`；`resistance/` 为 protected，脚本会跳过直写。
3. **垃圾回收**：`python scripts/garbage_collect.py audit` 无问题；
   `clean --yes` 清空 `tmp/`；缓存只留在用户缓存目录。
4. **计划任务**：`planned_tasks/` 保持声明态（无到期任务即空目录 + README + template）；
   **技能自身不执行**任何计划任务。
5. **git 操作**：各功能分支 `--no-ff` 合入 `dev`；整体审查通过后 `dev` 合入 `main`；
   本仓无远端，**不执行 push**（要加远端须先判可见性并征得用户确认）。
6. **产物清单**：输出文件树、行数、脚本数、依赖数、九项审查结论。
7. **过程链收口**：`process_chain.py step 收尾` + `finish --path create`。

## 返回机制

创建路径完成 = 收口返回调度方（SMS 主流程）由其整合续排；**不以本技能完成结束整段任务**。
