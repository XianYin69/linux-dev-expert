# 知识库构建

把经验查询的取证结果写成九叶知识 + 检查清单 + 出处索引，穷尽到不可再拓扑。

## 节点

1. **知识叶**：`asset/knowledge/<leaf>.md`，每叶三段——判据、坑位、取证命令，≤ 50 行。
2. **检查清单**：`asset/checklists/<leaf>.md`，逐条可勾选，交付前必过；
   未勾选不得称「已验证」。
3. **出处索引**：`references/` 分类记原始链接与用途（标准与手册 / 系统与服务 /
   工具链与打包 / 排障与性能 / 书目），每条带访问日期。
4. **机读树**：`asset/knowledge_tree.json` 与 `references/知识树.md` 双向一致。
5. **穷尽判定**：任一分面都能落到某叶主问句、且无叶可再拆 → 判「不可再拓扑」并冻结。
6. **验证**：`knowledge_index.py --list` 输出九叶；`check_links.py` 悬空为 0。

## 判据

- 只写判据与坑位，不写教程叙述（叙述指向 references 出处）。
- 未取证条目行首标 `[未取证]`；版本敏感结论必须带版本号。
- 他技能正文不得复制进来（[`薄技能依赖约束`](../../../resistance/薄技能依赖约束/薄技能依赖约束.md)）。

## 出口

`process_chain.py step 知识库构建`，提交 `feature/knowledge`。
