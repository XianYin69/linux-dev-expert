# 整体审查

按 [`../../resistance/审查约束/审查约束.md`](../../../resistance/审查约束/审查约束.md) 的九项标准逐项过。

## 节点

1. **结构完整**：目录与文件清单齐备（SKILL.md、agent/ 四格式、asset/、references/、
   dependence/、resistance/、branch/、planned_tasks/、scripts/、LICENSE、CHANGELOG.md、.gitignore）。
2. **frontmatter**：`name/version/description/license/metadata.category` 齐全，`name` = 目录名。
3. **行数红线**：`python scripts/run_tests.py`（含 md ≤ 50 行）全绿。
4. **链接零悬空**：`python scripts/check_links.py` 报告 `dangling: 0`。
5. **脚本真实存在**：SKILL.md 与 knowledge_tree.json 提到的脚本逐个存在且可编译。
6. **依赖合规**：`python scripts/deps_check.py` 通过（字段齐全、`source_url` 非空）。
7. **约束齐备**：resistance/ 含平台四约束 + 结构三约束 + 五大机制 + 沙盒。
8. **知识树不可再拓扑**：九叶互斥、并集覆盖、每叶有主问句/知识/清单/探针/出处。
9. **git 合规**：`feature/*` → `dev` → `main` 记录完整，无直写，工作树干净，无远端。

## 双链辩论

审查结论前先自辩：`python scripts/logic_chain.py debate --claim <论断> --pro ... --con ...`
（如「九叶是否已不可再拓扑」），裁决入链，最终判断在本技能。

## 失败处置

任一项不过 → `process_chain.py interrupt --at 整体审查 --reason <归因>`，
回对应步骤修复后 `resume`；重试计数走 `penalty.py bump`，达 10 次熔断。

## 出口

九项全绿 → `process_chain.py step 整体审查`，`dev` 合入 `main`。
