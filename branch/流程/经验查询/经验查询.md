# 经验查询

在写知识之前先取权威经验：标准、上游文档、实测，不靠记忆。

## 节点

1. **列取证清单**：按需求命中的知识叶（`python scripts/knowledge_index.py <关键词>`），
   为每叶列出需要的出处（man 页、内核文档、systemd 文档、发行版政策）。
2. **本地优先**：目标机有手册就先 `man 2 <name>` / `systemctl --version` 等实测取证。
3. **联网补充**：本地无手册或版本存疑时检索上游原始页，回填访问日期到
   [`references/`](../../../references/references.md)；未确证条目标 `[本地]`，禁止臆造 URL。
4. **发行版差异核对**：同一功能在不同族的包名/路径/默认值差异，逐族记录。
5. **失败经验**：查历史错误（同类故障的根因与修法），避免重复踩坑。
6. **沉淀**：结论写进 `tmp/`，标注「取证命令 + 出处 + 版本适用区间」。

## 判据

- 只有出处没有实测的结论 → 标 advisory；只有实测没有出处的结论 → 标「本机特定」。
- 版本敏感结论必须写清适用区间（如 glibc ≥ 2.34、内核 ≥ 5.10）。

## 出口

`process_chain.py step 经验查询`；取证清单入逻辑链。
