# 脚本构建

先写探针（取证能力），再写机制脚本（流程与红线自检），全部英文文件名。

## 节点

1. **探针清单**：12 个 `probe_*.py`，每个对应一类必须实测的环境事实
   （os / pkg / toolchain / systemd / ports / handles / caps / tracing / fs / elf /
   locale / cgroup），见 [`../../scripts/scripts.md`](../../../scripts/scripts.md)。
2. **统一约定**：共享逻辑进 `scripts/_common.py`；输出 `key=value` 或 `--json`；
   非 Linux 宿主返回 `applicable=false` 而不是崩溃；缺命令返回 `missing:<name>`。
3. **机制脚本**：`check_links`、`deps_check`、`knowledge_index`、`advice_compose`、
   `run_tests`、`logic_chain`、`process_chain`、`penalty`、`garbage_collect`、
   `context_compress`、`sandbox`、`self_update`。
4. **代码红线**：禁裸 `except`（须 `except <类型> as exc`）、禁调试残留、
   单行 ≤ 100 字符、函数不超一屏；`.py` 不限行数但按职责拆分。
5. **审核**：`python scripts/run_tests.py`（编译 + 冒烟 + 行数）必须全绿；
   失败按 [`惩罚机制`](../../../resistance/惩罚机制/惩罚机制.md) 计数。
6. **落盘**：先在 `tmp/` 镜像，`self_update.py compare` 后 `release --yes`。

## 出口

`process_chain.py step 脚本构建`，提交 `feature/scripts`。
