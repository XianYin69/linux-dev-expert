# 流程（Process）

linux-dev-expert 的执行流程细则。每个步骤独立成文件夹，文件夹名 = 流程名。

## 两条独立路径

### 创建流程

```
[初始化/](初始化/初始化.md) → [需求确认/](需求确认/需求确认.md) → [经验查询/](经验查询/经验查询.md) →
[大纲构建/](大纲构建/大纲构建.md) → [分支分析/](分支分析/分支分析.md) → [脚本构建/](脚本构建/脚本构建.md) →
[知识库构建/](知识库构建/知识库构建.md) → [约束编写/](约束编写/约束编写.md) →
[整体审查/](整体审查/整体审查.md) → [收尾/](收尾/收尾.md) → 完成
```

完成收尾后创建流程结束，不进入修改流程。

### 修改流程

```
[初始化/](初始化/初始化.md) → [修改流程/](修改流程/修改流程.md) → 完成（标记「完成项目修改」）
```
