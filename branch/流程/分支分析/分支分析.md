# 分支分析

对每个可能分叉的决策点，写清约束、降级路径与判据，避免执行期临时拍脑袋。

## 分叉点与处置

| 分叉 | 判据 | 降级 |
|---|---|---|
| 有/无 systemd | `ps -o comm= -p 1` | 改脚本 + supervisor/s6/runit 或 cron |
| glibc/musl | `ldd --version`、`/lib/ld-musl-*` | 重编 musl 版或换基础镜像 |
| deb/rpm/apk 族 | `/etc/os-release` | 按族并列给命令，不混用 |
| cgroups v1/v2 | `/sys/fs/cgroup` 挂载类型 | 用 v1 对应控制文件路径 |
| WSL/真机/容器 | `probe_os.py` 的 `is_wsl`/`is_container` | 标注差异，性能数字不跨域引用 |
| 有/无 root | `id`、`probe_caps.py` | capability / 用户级单元 / polkit |
| 有/无网络 | 目标机连通性 | 离线包 + 本地手册，标「未联网取证」 |
| 追踪工具缺失 | `probe_tracing.py` | 退到 `/proc` + strace 或 perf 最小集 |

## 节点

1. 逐分叉写「判据命令 → 分支结论 → 降级动作」三段。
2. 每个分叉的约束落到 [`../../resistance/`](../../../resistance/resistance.md) 对应文件。
3. 不确定即询问用户，不得擅自选一个分支当默认。

## 出口

`process_chain.py step 分支分析`；分叉表入逻辑链。
