# 约束编写

把分支分析得到的分叉判据写成不可逾越的约束，并接上五大机制兜底。

## 节点

1. **平台约束**（本技能特有）：
   [`探测优先约束`](../../../resistance/探测优先约束/探测优先约束.md)、
   [`破坏性命令约束`](../../../resistance/破坏性命令约束/破坏性命令约束.md)、
   [`root权限约束`](../../../resistance/root权限约束/root权限约束.md)、
   [`WSL与真机差异约束`](../../../resistance/WSL与真机差异约束/WSL与真机差异约束.md)。
2. **结构约束**：[`薄技能依赖约束`](../../../resistance/薄技能依赖约束/薄技能依赖约束.md)、
   [`git工作流约束`](../../../resistance/git工作流约束/git工作流约束.md)、
   [`审查约束`](../../../resistance/审查约束/审查约束.md)、
   [`约束部分`](../../../resistance/约束部分/约束部分.md)。
3. **五大机制**：垃圾回收、上下文压缩、逻辑链、过程链存取、惩罚；
   外加 [`沙盒机制`](../../../resistance/沙盒机制/沙盒机制.md) 兜底。
4. **合并规则**：同主题约束合并到一处，不重复表述；冲突时以更严者为准并记逻辑链。
5. **写法**：每条约束含「规则 / 降级 / 违反后果 / 相关」四段，≤ 50 行，自然语言。
6. **保护**：`resistance/` 内容不得删除；变更须走 `self_update.py`（其会跳过 protected）。

## 出口

`process_chain.py step 约束编写`，提交 `feature/resistance`。
