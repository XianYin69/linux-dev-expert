# 初始化

两条路径的共同前置步骤。产出：工作空间、MIT 许可、计划任务目录、git 功能分支。

## 节点

1. **建工作空间**：确认目标目录；未指定则 `python scripts/sandbox.py create` 走沙盒
   （见 [`沙盒机制`](../../../resistance/沙盒机制/沙盒机制.md)）。
2. **加入 MIT 协议**：技能根写 `LICENSE`（MIT 全文），已有则不覆盖。
3. **建 ignore**：`.gitignore` 含 `tmp/`、`__pycache__/`、`*.pyc`、IDE 目录、`private/`。
4. **建立计划任务目录**：`planned_tasks/README.md` + `template.json`；
   一任务一文件 `pt-linux-dev-expert-<slug>.json`，**技能自身不执行**，到期交 SMS 调度器。
5. **git 初始化**：无 `.git` 即 `git init`；建 `main` 基线提交，切 `feature/init`。
6. **过程链开账**：`python scripts/process_chain.py start --path create`。
7. **tmp 镜像就位**：所有后续写盘先落 `tmp/`，经 `self_update.py compare` 再释放。

## 判据

- 目标目录已存在且非空 → 走修改路径，不得覆盖既有内容。
- 已有 `LICENSE`/`planned_tasks/` → 跳过对应节点并在逻辑链记「已存在，不覆盖」。

## 出口

`python scripts/process_chain.py step 初始化` + `git commit` 到 `feature/init`。
